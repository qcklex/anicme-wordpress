# anicme WordPress site (static export)

Static export of the public pages of https://wordpress.anicme.org/ taken on 9 Nov 2026: rendered HTML, theme and plugin assets and uploads exactly as the site serves them, under site/.

This is not the WordPress source. It has no database, no wp-config.php, no theme or plugin PHP and no admin or API endpoints. The Stripe live publishable key and account id that appear in the cart and gift-voucher pages are replaced with REDACTED.

To keep the real site, export it from the IONOS hosting (files and database) and keep that backup private.

The main anicme.org site is in the separate repository qcklex/anicme-org.
